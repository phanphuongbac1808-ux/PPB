# Đánh giá đầu vào

Điền bằng cách Edit file trên GitHub. Không điền mã sinh viên, số điện thoại hoặc thông tin riêng tư: kho này công khai.

- Năm học: chưa điền
- Thời gian học mỗi tuần: chưa điền
- Board/cảm biến/thiết bị đo được dùng: chưa điền
- Hướng muốn trải nghiệm: nhúng / tự động hóa / thiết kế mạch — chưa chọn

## Thang tự đánh giá

0 = chưa biết; 1 = hiểu khi được hướng dẫn; 2 = tự thực hiện; 3 = tự thực hiện và giải thích/kiểm tra được.

| Kỹ năng | Mức 0–3 | Bằng chứng hoặc chỗ đang vướng |
|---|---|---|
| Tính điện áp, dòng và công suất | | |
| Đọc sơ đồ mạch | | |
| Đo bằng đồng hồ đúng cách | | |
| C: hàm, mảng, bit | | |
| Đọc datasheet tiếng Anh | | |
| GPIO/ADC/timer | | |
| UART/I²C/SPI | | |
| PLC và logic điều khiển | | |
| Python xử lý CSV | | |
| Tìm lỗi và ghi kết quả | | |

## Bài kiểm tra nhỏ

- Tính dòng qua điện trở 1 kΩ khi có 5 V, rồi tính công suất. Nêu giả định.
- Giải thích khác nhau giữa đo điện áp và đo dòng bằng đồng hồ.
- Viết hàm C tìm giá trị lớn nhất của mảng; xác định cách xử lý mảng rỗng.
- Đọc một bảng thông số cảm biến và tìm điện áp hoạt động, giao tiếp, giới hạn đo.

Nếu chưa làm được, ghi rõ điểm vướng; mục tiêu là chọn bài học tiếp theo, không phải chấm điểm bản thân.
